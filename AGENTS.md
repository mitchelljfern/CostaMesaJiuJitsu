# Rules for AI tools and anyone editing this site

This is the website for Costa Mesa Jiu Jitsu (costamesajiujitsu.com). If you are an AI coding tool (Cursor, Claude, Grok, Copilot, anything else), read this whole file before you change anything. These rules come from Mitchell, who owns the repo and approves every change that goes live.

## The five rules

1. **Work on `staging`. Never on `main`.** `main` is the live site and is locked. Start from `staging`, and send your work back to `staging`. If your tool opens pull requests, the base branch must be `staging`, not `main`.
2. **Edit the code that is already here.** No frameworks, no build tools, no packages, no new stylesheets or script files, no rewrites. This site is plain HTML, CSS and JavaScript on purpose. If a change seems to need something new, stop and ask Mitchell.
3. **Never edit a generated file by hand.** Change the source, then run the build (see "Source and generated files").
4. **Keep the change small.** Change only what was asked. Do not reformat, re-indent, rename or "clean up" anything else. A reviewer has to read every line you touch.
5. **Run `python3 tools/check.py` before every push** and fix everything it reports. It rebuilds the site and checks for the common mistakes. Do not push if it fails.

## How a change goes live

```
edit on staging  ->  python3 tools/check.py  ->  push to staging  ->  check the staging site
      ->  open a pull request from staging into main  ->  Mitchell approves  ->  live
```

- Staging site: https://staging--costa-mesa-jiu-jitsu.netlify.app (updates about a minute after a push to `staging`)
- Live site: https://costamesajiujitsu.com (updates only when Mitchell merges into `main`)
- Only Mitchell can approve a pull request into `main`. Do not try to merge it, and do not ask anyone else to approve it.
- Every merge into `main` costs Netlify credits. Put all of a day's changes into one pull request.
- In the pull request, say in plain English what changed and why. Mitchell is not a programmer.

| `tools/llms.txt` | The plain-text summary for AI assistants. |

**Never edit these by hand (generated by the build):**

`free-trial/`, `kids-jiu-jitsu/`, `pricing/`, `private-lessons/`, `brady-fink/`, `upcoming-tournaments/`, `privacy-policy/`, `terms-of-service/`, `waiver/`, `assets/site.css`, `assets/pages.js`, `_redirects`, `sitemap.xml`, `robots.txt`, `404.html` and the `llms.txt` in the top folder.

**To rebuild:** `python3 tools/check.py` (it runs both build scripts, then checks the result). It needs only Python 3, nothing to install. Commit the generated files together with your source change.

**Styles** live in the `<style>` block of `index.html`. The build copies them into `assets/site.css`. Add or change styles there, next to the related rules.

## Changing the schedule

A class time appears in all of these places. Change every one, then run the check, which compares them.

In `index.html`:
1. The weekly schedule cards: search `id="week"`.
2. The Next Class countdown data: search `var SCHED`. Format is `[day, hour, minute, 'Name', 'Detail']`, day 0 is Sunday, hours are 24-hour.
3. The free class form's class list: search `id="cls"`.
4. The three program cards (Little Ninjas, Youth, Adult): search `class="times"`.
5. The contact section's "Class days" block: search `class="hours"`, plus the sentence under it.
6. Any pricing card text that mentions days (for example "five days a week").

Elsewhere:
7. `tools/build.py`: the kids page mentions how many days a week kids can train.
8. `tools/llms.txt`: the "Weekly jiu jitsu schedule" list.

Current schedule: Monday to Friday, Little Ninjas 4:15 PM, Youth 5:15 PM, Adults 6:15 PM. Gi on Monday, Wednesday and Thursday. NoGi on Tuesday and Friday. Saturday Open Mat at 11:00 AM. No classes Sunday.

## Changing a price

1. `index.html`: the pricing cards (search `id="pricing"`).
2. `index.html`: the data Google reads, near the top (search `"@type": "Offer"`).
3. `tools/build.py`: search for the old price. It appears in the pricing page, the kids page and their descriptions.
4. `tools/llms.txt`: the "Memberships" line.

Current prices: Unlimited Adult $189/month, Unlimited Kids $179/month, Family Add-On $120/month, 10-Class Pack $250.

The **Sign up** and **Buy a pack** buttons go to Stripe checkout links, one per plan. A Stripe link charges a fixed price, so a price change needs a new Stripe link from Mitchell or Tony. Never change a price on the site without the matching link. The Unlimited Kids link appears twice: on its card in `index.html` and as `STRIPE_KIDS` in `tools/build.py`.

## Do not touch without asking Mitchell

- **The text message consent checkbox** on the forms, and its wording. Phone carriers approved the gym's texting number based on it. It must stay unchecked, required, word for word, and just above the submit button.
- **The privacy policy and SMS terms wording.** Several lines are required word for word.
- **Form handling:** `assets/lead-gate.js`, the HighLevel tracking script, the Google tag, and the form `id` and `name` attributes. Leads flow into the gym's CRM through these.
- **`netlify.toml`, `.github/`, `_redirects`** and anything about deploys, branches or domains.
- **The waiver terms** (`tools/waiver-terms.html`). Signed waivers point at a dated version.
- **Outside scripts, fonts, trackers or embeds.** Do not add any.

## Content rules

- Never use em dashes. Use commas, periods or parentheses.
- The address is always written "2428 Newport Blvd, Unit 7, Costa Mesa, CA 92627".
- The $99 Beginners Jiu Jitsu Program was removed in November 2026. Do not add it back or mention it.
- Kickboxing and yoga are off the site until they return. Do not add them.
- Coach Darby no longer works here. No mentions or photos.
- Real gym photos only, no stock images. Photos go in `photos/` as `.webp` under about 200 KB.
- This gym is no longer part of Double Ops. No Double Ops logos or wording.
- Colors, fonts and logo files are documented at `/brand-kit/`. Use what is there.
- The site has a light and a dark mode. Check both after any visual change.
- Most visitors are on phones. Check every change at phone width.

## If you are unsure

Stop and ask Mitchell instead of guessing. A question costs nothing. A wrong guess on a gym's schedule or prices costs the gym customers.
